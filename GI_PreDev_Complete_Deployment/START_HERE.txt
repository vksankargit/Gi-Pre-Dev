QUICK START - 3 SIMPLE STEPS
================================================================================

STEP 1: SETUP
-------------
Windows:
  1. Open Command Prompt in this folder
  2. Run: python -m venv venv
  3. Run: venv\Scripts\activate
  4. Run: pip install -r requirements.txt
  5. Run: setup_database.bat

Linux/Mac:
  1. Open Terminal in this folder
  2. Run: python3 -m venv venv
  3. Run: source venv/bin/activate
  4. Run: pip install -r requirements.txt
  5. Run: chmod +x *.sh
  6. Run: ./setup_database.sh

STEP 2: START
------------
Windows: Run quick_start.bat
Linux/Mac: Run ./quick_start.sh

STEP 3: ACCESS
-------------
Open your browser and go to: http://localhost:8000

That's it! You're ready to use the GI Pre-Dev System!

HELP AND SUPPORT

Problem? Check these in order:

2. README.md (Common issues)
3. Django logs/error messages
4. Browser console (F12)

Common Issues:

"Python not found"
  → Install Python 3.8+ from python.org

"Module not found"
  → Run: pip install -r requirements.txt

"Server won't start"
  → Run: python manage.py check

"Port 8000 in use"
  → Run: python manage.py runserver 8001

PRODUCTION DEPLOYMENT
================================================================================

For production use:

IMPORTANT:
1. Change SECRET_KEY in pre_system/settings.py
2. Set DEBUG = False
3. Configure ALLOWED_HOSTS
4. Use PostgreSQL/MySQL instead of SQLite
5. Set up HTTPS
6. Configure proper web server (Nginx + Gunicorn)

See INSTALLATION_GUIDE.md for complete production deployment guide.
